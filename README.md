# Mortar

Writes version-control history for agent teams: makes the folders agents work in, saves their work, joins a
request to its zone, makes a zone's squash, lands it, and guards integration and origin. Plain git underneath.

Mission and feature list: `~/dev_docs/forge-design/MISSION-mortar-2026-11-11.md` and `8-MORTAR-feature-list.md`.
